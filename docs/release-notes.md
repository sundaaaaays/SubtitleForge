免安装绿色版，解压后双击 `SubtitleForge.exe` 即可使用。全程离线运行，不联网、不写注册表。

这一版主要解决「导入多个视频后，右边的字幕被后一个覆盖」的问题，并补上了视频预览和夜间模式。

## 新增

### 每个文件一个标签页，互不覆盖

以前所有文件共用一张字幕表，第二个文件转写完就把第一个顶掉了。现在一个文件对应一份独立文档和一张表，右侧按文件分标签页；左侧点谁右边就切到谁，两边联动。

### 视频预览窗（左侧中间）

- 有画面就直接显示，音频文件显示「音频文件，无画面」的提示
- 点字幕表格的「开始 / 结束 / 时长」列，播放器跳到那句开始播，画面同步跟过去
- 播放时表格自动高亮当前这句，预览窗下方进度条可拖动定位
- 画面是从解码帧自绘到画布上的，不是原生视频窗口，所以录屏和截图都能正常抓到

### 夜间模式

标题栏右侧「夜间模式 / 日间模式」一键切换（快捷键 Ctrl+D），选择会记住，下次启动保持。

### 识别参数可折叠

参数面板默认收起，只占一行标题。展开时预览窗自动收矮，避免文件列表被挤得只剩一行。

### 批量队列

点一次「开始转写」会把所有还没转写的文件排队处理，逐个出结果；进度和状态显示在左侧列表。中途点「取消」会停下整个队列。

## 改进

- 转写中的文件自动切到它自己的标签页，不用手动找
- 批量时单个文件失败不再弹窗打断，最后统一汇总成功 / 失败数量
- 全部转完后可以单独重转当前文件
- 「开始转写 / 取消」并排，窄窗口下也不会被挤出边界

## 使用方法

1. 解压到任意目录（建议非系统盘）
2. 双击 `SubtitleForge.exe`
3. 拖入音视频 → 点「开始转写」→ 点「导出…」

首次启动约 2~3 秒（要加载 229MB 模型）。转写速度大约 1 分钟音频用 3~5 秒（视 CPU 而定）。

## 系统要求

- Windows 10 / 11 64 位
- 不需要装 Python，也不需要装 FFmpeg，都已内置
- 内存 4GB 以上，磁盘预留 600MB

## 压缩包里有什么

| 路径 | 说明 |
| --- | --- |
| `SubtitleForge/SubtitleForge.exe` | 主程序 |
| `SubtitleForge/models/sensevoice/` | 识别模型，229MB，**别删** |
| `SubtitleForge/_internal/` | 运行时依赖（Qt、onnxruntime、ffmpeg），**别删** |
| `SubtitleForge/README.md` | 完整文档 |

## 已知限制

- 只做文件转写，不做实时麦克风字幕
- 不做说话人分离（区分「谁在说话」）
- 不做视频字幕压制，导出 SRT 后自行合成
- 中文按字切分，可能切在词中间（有意取舍，避免引入分词器增加体积）
